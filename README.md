# 🚀 My First Portfolio: Where it all began (2019)

This isn't just a code repository; it’s **Mile Zero** of my career as a developer.

I built this portfolio in 2019 with immense dedication and **a lot of heart**. It represents the exact moment I decided to start exploring the power of **Frontend**.

> 💡 **Let's be real:** Looking back, that design... let's just say my "pixel-perfect" definition has evolved *a lot* since then! 😂 But you know what? I’m still incredibly proud of it. It was the hardest I'd ever worked on a digital project at the time.

## ❤️ Why this project is special

* **The Foundation:** It was my first big challenge translating "pixel-perfect" (well, 2019 pixel-perfect) designs from my head directly to the web.
* **Self-Taught Spirit:** Every line of CSS and every JavaScript function here was the result of curiosity, too much coffee, and pure persistence.
* **UX First:** From day one, my priority was making the user feel "at home" while navigating. The seeds of my design thinking were planted here.
* **Evolution:** I keep this repository with pride because it shows where I come from. It’s a reminder that every great developer started with a single `index.html`.

## 🛠️ Built with

* **HTML5 & CSS3** (Handcrafted with love and many, many stacked `div`s).
* **JavaScript (ES6)** to bring some dynamism (and maybe a bug or two) to the interface.
* **Sass** Because even then, I knew organized styles were the future.
